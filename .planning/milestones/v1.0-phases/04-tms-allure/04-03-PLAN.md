1. Create **allure_types.go**: Go structs for Allure JSON format. All fields use pointers or omitempty for defensive parsing. GoDoc IN RUSSIAN.
- AllureResult: UUID, HistoryID, TestCaseID, FullName, Name, Status (all string), StatusDetails (*AllureStatusDetails), Stage, Start/Stop (*int64), Steps ([]AllureStep), Labels ([]AllureLabel), Links ([]AllureLink), Parameters ([]AllureParameter), Attachments ([]AllureAttachment), Description.
- AllureStatusDetails: Known, Message, Trace (all string, omitempty).
- AllureStep: Name, Status, Start/Stop (*int64), Steps (recursive []AllureStep), Parameters, Attachments.
- AllureLabel: Name, Value.
- AllureLink: Name, URL, Type.
- AllureParameter: Name, Value.
- AllureAttachment: Name, Source, Type.

2. Create **allure_parser.go**: Defensive parser function.
- `ParseAllureResults(data []byte) ([]AllureResult, error)`: Unmarshal JSON array of AllureResult. Return error for malformed JSON. Never panic. Log warnings for unexpected shapes via slog.Warn.
- `ParseAllureResult(data []byte) (*AllureResult, error)`: Parse single result (for individual file processing).
- Helper: `extractLabelValue(labels []AllureLabel, name string) string` -- nil-safe label extraction.
- Helper: `allureStatusToTMS(status string) string` -- map Allure statuses (passed/failed/broken/skipped/unknown) to TMS statuses.

3. Create **allure_matcher.go**: Multi-strategy test case matching.
- `Matcher` struct with `repo Repository` field.
- `NewMatcher(repo Repository) *Matcher`
- `MatchTestCase(ctx context.Context, result *AllureResult) (*ent.TestCase, MatchStrategy, error)`: Try strategies in priority order:
  1. Check links with type="tms" -- call repo.FindTestCaseByExternalID
  2. Check labels with name="AS_ID" or name="tms" -- call repo.FindTestCaseByExternalID
  3. Check fullName -- call repo.FindTestCaseByFullName
  4. Check suite label + name -- call repo.FindTestCaseByClassMethod
  5. Return nil, -1, nil if no match (unmapped)
- `MatchStrategy` type (int const): MatchByAnnotation, MatchByFullName, MatchByClassName.

4. Create **allure_parser_test.go**: Tests following TDD behavior spec above. Use testify. Create sample JSON fixtures inline:
- Valid JUnit-style result with all fields
- Minimal pytest-style result with most fields missing
- Result with @TestCase annotation in links
- Result with AS_ID label
- Result with only fullName
- Malformed JSON string
For matcher tests, use a mock repository that returns test cases only for specific lookups.

1. Create **mongo_repository.go**: MongoDB operations for raw Allure storage. Follow messenger mongo_repository.go pattern.
- `MongoRepository` struct with `db *mongo.Database` field.
- `NewMongoRepository(db *mongo.Database) *MongoRepository`
- `EnsureIndexes(ctx context.Context) error`: Create indexes on allure_results collection: (run_id + created_at), (allure_uuid).
- `StoreAllureResults(ctx context.Context, runID uuid.UUID, results []AllureResult) error`: Insert each result as a document with run_id, allure_uuid, raw (the AllureResult struct), created_at. Bulk insert with InsertMany.
- `GetAllureResultsByRunID(ctx context.Context, runID uuid.UUID) ([]AllureResult, error)`: Find by run_id, return raw results.
- `GetAllureResultByUUID(ctx context.Context, allureUUID string) (*AllureResult, error)`: Find single by allure_uuid.
GoDoc IN RUSSIAN.

2. Create **combined_repository.go**: Following messenger combined_repository.go pattern exactly.
- `CombinedRepository` struct with `ent *EntRepository` and `mongo *MongoRepository`.
- `NewCombinedRepository(ent *EntRepository, mongo *MongoRepository) *CombinedRepository`
- All Ent repository methods delegated to `r.ent.*`
- All Mongo repository methods delegated to `r.mongo.*`
- Implements the full Repository interface.

3. Update **repository.go**: Add MongoDB methods to Repository interface:
- `StoreAllureResults(ctx context.Context, runID uuid.UUID, results []AllureResult) error`
- `GetAllureResultsByRunID(ctx context.Context, runID uuid.UUID) ([]AllureResult, error)`

4. Update **service.go** -- add methods:
- `ImportAllureResults(ctx context.Context, projectID, userID uuid.UUID, req ImportAllureRequest) (*TestRunDetailResponse, error)`:
  1. Parse allure-results JSON using ParseAllureResults.
  2. Store raw results in MongoDB via repo.StoreAllureResults.
  3. Create TestRun with run_type="automatic" or use provided runID.
  4. For each result, match to test case using Matcher.MatchTestCase.
  5. Create TestResult entries: matched results link to test_case, unmatched have match_strategy="unmapped".
  6. Detect flaky tests: if same test case had different status in last 5 runs, mark is_flaky=true.
  7. Compute and save run stats (total, passed, failed, etc.).
  8. Set run status to "completed", set completed_at.
  9. Publish EventTestRunCompleted via NATS (nil-safe pattern from messenger).
  10. Return TestRunDetailResponse.
- `GetTestRunHistory(ctx, projectID uuid.UUID, limit int) ([]TestRunSummary, error)`: List last N runs with stats for trends.
- `GetFlakyTests(ctx, projectID uuid.UUID) ([]TestCaseResponse, error)`: List test cases with is_flaky=true on their latest result.

5. Update **handler.go** -- add endpoints:
- `POST /projects/:projectId/tms/allure/import` (PermTestRunCreate) -> ImportAllureResults. Accepts JSON body with `results` array (batch of AllureResult objects). Returns created TestRun with results.
- `POST /projects/:projectId/tms/runs/:runId/allure` (PermTestRunCreate) -> ImportAllureToExistingRun. Same but adds to existing run.
- `GET /projects/:projectId/tms/reports/history` (PermProjectView) -> GetTestRunHistory. Query param: limit (default 20).
- `GET /projects/:projectId/tms/reports/flaky` (PermProjectView) -> GetFlakyTests.
Swagger annotations IN RUSSIAN.

6. Update **dto.go**: Add ImportAllureRequest { Results json.RawMessage, Title string (optional), AllureRunID string (optional) }. Add TestRunSummary { RunID, Title, Total, Passed, Failed, PassRate float64, CreatedAt }.

7. Update **main.go**: Switch TMS from EntRepository to CombinedRepository:

```go
tmsEntRepo := tmsmod.NewEntRepository(db)

tmsSvc := tmsmod.NewTMSService(tmsRepo)
```
Pass NATS client to TMSService constructor if not already done (for event publishing).
