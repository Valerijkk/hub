2. Создать `frontend/src/api/calls.ts` — API-клиент по паттерну messenger.ts:
   - `createCall(channelId: string)` — POST /api/calls, body: { channel_id: channelId }
   - `joinCall(callId: string)` — POST /api/calls/{callId}/join
   - `leaveCall(callId: string)` — POST /api/calls/{callId}/leave
   - `endCall(callId: string)` — POST /api/calls/{callId}/end
   - `getActiveCall(channelId: string)` — GET /api/calls/channel/{channelId}, вернуть null при 404
   - `raiseHand(callId: string, raised: boolean)` — POST /api/calls/{callId}/raise-hand, body: { raised }
   - Типы: CallResponse, CallParticipantResponse — матчить backend DTOs.
   - Использовать apiClient из client.ts.

3. Создать `frontend/src/stores/callStore.ts` — Zustand store:
   - State: activeCall (CallResponse | null), token (string | null), isInCall (boolean), isConnecting (boolean), error (string | null)

   - Использовать паттерн из существующих stores (immer middleware если используется).

   - Props: token (string), serverUrl (string), onDisconnect (() => void).

2. Создать `frontend/src/components/calls/CallControls.tsx`:
   - Кастомная панель управления (НЕ использовать ControlBar напрямую — нужна кнопка raise hand).
   - Хуки: useLocalParticipant() для mic toggle, useRoomContext() для screen share.
   - Кнопки:
     - Mic toggle: localParticipant.isMicrophoneEnabled, toggle через localParticipant.setMicrophoneEnabled(!current)
     - Screen share: track.source === Track.Source.ScreenShare, toggle через room.localParticipant.setScreenShareEnabled(!current). Браузер автоматически покажет пикер экрана/окна.
     - Raise hand: POST /api/calls/:callId/raise-hand через useCallStore. Визуально: иконка руки, подсвечена когда поднята.
     - Leave: useCallStore().leaveCall(), вызвать onDisconnect.
     - End call (только для создателя): useCallStore().endCall().
   - Стилизация: Tailwind, flex row, gap-2, кнопки с иконками (Lucide: Mic, MicOff, Monitor, Hand, PhoneOff).
   - Shadcn Button variants: default для active, destructive для leave/end.
