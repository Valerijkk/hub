## Decisions Made

- Used next-themes with `attribute="class"` for Tailwind dark mode (class-based toggling)
- Accent colors implemented via `data-accent` HTML attribute with oklch CSS variable overrides
- Static JSON imports for locale files (no lazy loading) -- appropriate for current app scale
- VitePWA `maximumFileSizeToCacheInBytes` set to 4MB to accommodate large JS bundle
- External manifest.webmanifest used (manifest: false in VitePWA) for full control
