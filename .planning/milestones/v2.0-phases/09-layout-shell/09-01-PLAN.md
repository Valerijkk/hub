
`shadow-[0_0_12px_var(--primary),0_0_30px_rgba(91,156,245,.15)]`
This gives the accent glow effect. For users with different accents, the first shadow part (var(--primary)) will change automatically.

**Active gradient overlay** — add another conditional span for the left-to-right gradient:
```tsx
{isActive && !collapsed && (

)}
```
Since rgba with CSS var is tricky, use a simpler approach: `bg-gradient-to-r from-primary/[0.06] to-transparent` — this works with Tailwind v4.

**Icon styles** — update:
- Default: `opacity-45` on the svg wrapper span

**Badge** — keep current badge styling (red pill).

**NAV_ICON_COLORS** — keep the per-route icon color map as-is.
