Two changes:

1. **theme-provider.tsx** — Remove the `disableTransitionOnChange` prop from NextThemesProvider (line 109). This prop currently strips all CSS transitions during theme switch to prevent FOUC, but it causes an abrupt flash. Without it, next-themes will allow CSS transitions to run during the class toggle, producing a smooth crossfade.

The updated JSX:
```tsx
<NextThemesProvider
  attribute="class"
  defaultTheme="system"
  enableSystem
>
```

2. **app.css** — Add a theme transition rule in the `@layer base` block, right after the body rule (after line 387). This ensures background-color and color smoothly transition on theme toggle:

```css
/* Theme toggle smooth transition */
html, body,
.bg-background, .bg-base, .bg-card, .bg-raised, .bg-void,
[class*="bg-gradient"] {
  transition: background-color 200ms var(--ease), color 200ms var(--ease), border-color 200ms var(--ease);
}
```

This targets the key surfaces that visually flash on theme switch. The 200ms duration with the project's --ease curve matches the success criteria.
