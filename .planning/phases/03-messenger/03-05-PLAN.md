   - Архитектура модуля:
     - Dual-storage: Ent (PG) для метаданных каналов + MongoDB для сообщений. Обоснование.
     - Структура файлов: handler.go, service.go, repository.go, ent_repository.go, mongo_repository.go, presence.go, unread.go, auto_channels.go, dto.go, events.go.
     - Диаграмма потока данных: Client -> REST/WS -> Handler -> Service -> Repository (Ent/MongoDB) -> NATS -> Bridge -> WS -> Client.
   - Ent-схемы:
     - Channel: поля, edges, indexes. dm_key для DM дедупликации.
     - ChannelMember: поля, unique index (channel_id, user_id).
     - Bookmark, PinnedMessage.
   - MongoDB:
     - Коллекция messages, структура документа MessageDocument.
     - Индексы: compound (channel_id, created_at), thread (channel_id, thread_id, created_at), text (content_text).
     - Cursor pagination паттерн.
   - NATS:
     - Subject conventions: messenger.channel.{id}.message_sent/edited/deleted/reaction_toggled/typing/member_joined/member_left.
     - Bridge расширение: handleMessengerEvent -> room "channel:{channelID}".
     - Core NATS (не JetStream) для ephemeral events.
   - Redis:
     - Presence: sorted set "presence:online", score = timestamp. Heartbeat 30s, away >5min, offline >90s.
     - Unread: hash "unread:{userID}", field = channelID, value = count.
     - Cleanup loop каждые 60 секунд.
   - REST API:
     - Полный список эндпоинтов с методами, параметрами, response types.

     - Hooks: useMessages (TanStack Query + WS), useChannels, usePresence (polling 30s), useUnread.
     - Store: messenger-store (activeChannelId, channels, unreadCounts).
     - Виртуализация: @tanstack/react-virtual для chat-view.
   - Автоканалы:
     - NATS subscription project.*.created.
