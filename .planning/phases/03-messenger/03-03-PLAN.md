PUT    /api/messenger/channels/:id/messages/:msgId -> edit message

POST   /api/messenger/channels/:id/messages/:msgId/reactions -> toggle reaction
POST   /api/messenger/channels/:id/messages/:msgId/pin -> toggle pin
POST   /api/messenger/channels/:id/messages/:msgId/forward -> forward
GET    /api/messenger/channels/:id/messages/:msgId/replies -> thread replies
POST   /api/messenger/dm                    -> create/get DM
GET    /api/messenger/search                -> search messages
GET    /api/messenger/bookmarks             -> list bookmarks
POST   /api/messenger/bookmarks             -> add bookmark
DELETE /api/messenger/bookmarks/:id         -> remove bookmark
