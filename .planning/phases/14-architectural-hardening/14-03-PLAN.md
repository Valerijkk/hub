## Goal
Удалить `*ent.Client` из MessengerService, AuditService, SearchService. Все запросы — через
Repository интерфейсы. Это устраняет LO-03 (`ent.Client leak` в сервисах) и завершает
вытеснение Ent ORM из бизнес-логики.

## Scope

**In:**

### 1. MessengerService
Текущее: `db *ent.Client` хранится в struct, прямые запросы из `service.go` (resolveGroupMentions @role mention), `service_channel_invites.go` (ChannelInvite CRUD), `service_polls.go` (Poll + PollVote + Tx).

**Цель:** добавить методы в `Repository` interface + `EntRepository` impl, удалить поле `db` из `MessengerService`.

### 3. SearchService
Текущее: `db *ent.Client` хранится для `getUserProjectIDs` (project_members query), `isSystemAdmin` (User.Get), SavedFilter CRUD (Create/Query/Get/Delete/Update).

**Цель:** ввести `search.Repository` интерфейс. SearchService использует только `sqlDB *sql.DB` (для raw tsvector queries) и `mongoDB *mongo.Database` (для $text) — это нормально, **БД-уровневые** оптимизации, не ORM-уровневые. Удаляем `*ent.Client`.

```go
    DeleteSavedFilter(ctx context.Context, filterID uuid.UUID) error
    UpdateSavedFilterShared(ctx context.Context, filterID uuid.UUID, shared bool) (*ent.SavedFilter, error)
}

type EntRepository struct { db *ent.Client }
func NewEntRepository(db *ent.Client) *EntRepository  // implements Repository
```

**Обновить:**
- `SearchService` struct: убрать `db *ent.Client`, добавить `repo Repository`.
- `NewSearchService` сигнатура: `func NewSearchService(repo Repository, sqlDB *sql.DB, mongoDB *mongo.Database) *SearchService`.

## Risk + Rollback
- **Risk:** Транзакция в `service_polls.go: CreatePoll/VotePoll` (`s.db.Tx(ctx)`) уйдёт в репозиторий — нужно аккуратно перенести Tx-замыкание чтобы не потерять транзакционность голосования. Pattern: `CreatePollWithOptions(ctx, input)` сам открывает Tx внутри.
- **Risk:** SavedFilter методы Search service возвращают `*ent.SavedFilter` напрямую — это утечка ent-типов в сигнатуру публичных методов сервиса. **Допустимо для этой фазы** (это task для будущего "no ent in public service signatures"). Достаточно убрать `*ent.Client`-зависимость.
- **Rollback:** Три атомарных коммита (`refactor(messenger): remove ent.Client from service`, `refactor(audit): ...`, `refactor(search): ...`) + один итоговый main.go-коммит. Откат каждого независим.
