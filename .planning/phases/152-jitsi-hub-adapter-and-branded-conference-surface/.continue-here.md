2. Provider control URLs and browser connection URLs are distinct. Existing `LIVEKIT_URL` stays server-side; Phase 152 introduces an explicit validated browser URL. Jitsi continues to use configured `JITSI_PUBLIC_URL`, never ambient browser origin.
3. Credential issuance becomes a typed, call-aware provider request built only after Hub authz. The request carries call ID, canonical room, server-resolved participant identity/name, and member/guest kind; providers do not authorize users.
