**service.go** -- add methods:
- `LinkTestCaseToIssue(ctx, caseKey string, issueID uuid.UUID) error`: Find test case by key, link to issue. Publish EventTestCaseLinked.
- `UnlinkTestCaseFromIssue(ctx, caseKey string, issueID uuid.UUID) error`: Remove link.

- `GetCoverageReport(ctx, projectID uuid.UUID) (*CoverageReport, error)`: For each issue that has linked test cases, show the issue + test cases + their latest result status. Returns list of IssueCoverage{ Issue, TestCases []TestCaseCoverage{ TestCase, LastResultStatus } }.
- `GetTestTrends(ctx, projectID uuid.UUID, lastN int) ([]TrendPoint, error)`: For last N runs, return TrendPoint{ RunID, Title, Total, Passed, Failed, Skipped, Broken, PassRate, CreatedAt }.
- `GetRunComparison(ctx, runID1, runID2 uuid.UUID) (*RunComparison, error)`: Compare two runs side-by-side showing changed statuses.

- `POST /cases/:caseKey/links` (PermTestCaseEdit) -> LinkTestCaseToIssue. Body: { issue_id: string }.
- `DELETE /cases/:caseKey/links/:issueId` (PermTestCaseEdit) -> UnlinkTestCaseFromIssue.
- `GET /cases/:caseKey/links` (PermProjectView) -> GetTestCaseLinkedIssues.
- `POST /runs/:runId/results/:resultId/bug` (PermTestCaseEdit) -> CreateBugFromFailedResult. Body: { title, description, priority }.
- `GET /reports/coverage` (PermProjectView) -> GetCoverageReport.
- `GET /reports/trends` (PermProjectView) -> GetTestTrends. Query: limit (default 20).
- `GET /reports/comparison` (PermProjectView) -> GetRunComparison. Query: run1, run2.

2. Create **importer.go**: Multi-format test case import with field mapping. GoDoc IN RUSSIAN.
- `ImportFormat` type: CSV, JSON, XML, Excel.
- `FieldMapping` struct: map[string]string where key=source column name, value=TMS field name (title, description, precondition, steps, priority, status, case_type).
- `AutoDetectMapping(headers []string) FieldMapping`: Case-insensitive match on known field names ("Title"/"Название"/"Test Name" -> "title", "Steps"/"Шаги" -> "steps", "Priority"/"Приоритет" -> "priority", etc.).
- `ImportFromCSV(reader io.Reader, mapping FieldMapping) ([]CreateTestCaseInput, error)`: Parse CSV using encoding/csv. Map columns using mapping. Return list of inputs.
- `ImportFromJSON(reader io.Reader) ([]CreateTestCaseInput, error)`: Parse JSON array of objects. Auto-map fields.
- `ImportFromXML(reader io.Reader) ([]CreateTestCaseInput, error)`: Parse XML with `<testcases><testcase>` structure. Map elements.
- `ImportFromExcel(reader io.Reader, sheetName string, mapping FieldMapping) ([]CreateTestCaseInput, error)`: Parse XLSX using excelize. Read first sheet by default. First row = headers. Map columns using mapping.
- `ValidateImportData(inputs []CreateTestCaseInput) []ImportValidationError`: Validate each input (title required, valid priority, etc.). Return errors with row numbers.

3. Create **exporter.go**: Multi-format export. GoDoc IN RUSSIAN.
- `ExportTestCasesToCSV(writer io.Writer, cases []TestCaseExportData) error`: Write CSV with headers: Key, Title, Type, Priority, Status, Steps, Precondition, Suite.
- `ExportTestCasesToJSON(writer io.Writer, cases []TestCaseExportData) error`: Write JSON array.
- `ExportTestCasesToXML(writer io.Writer, cases []TestCaseExportData) error`: Write XML with `<testcases>` root.
- `ExportTestCasesToExcel(writer io.Writer, cases []TestCaseExportData) error`: Write XLSX using excelize. Bold headers, column widths auto-set, alternating row colors.
- `ExportTestRunToPDF(writer io.Writer, run TestRunExportData) error`: Generate PDF report using maroto v2. Include: Title, stats table (total/passed/failed/skipped), results table with status, pass rate chart (simple bar). Header with project name and date.
- `TestCaseExportData` struct: Key, Title, Type, Priority, Status, Steps (formatted text), Precondition, Suite.
- `TestRunExportData` struct: Title, CreatedAt, Stats, Results []ResultExportData.

4. Update **service.go**:
- `ImportTestCases(ctx, projectID, userID uuid.UUID, req ImportRequest) (*ImportResult, error)`: Parse file using appropriate importer (detect format from Content-Type or explicit format field). Auto-detect or use provided mapping. Validate. Create test cases in batch. Return ImportResult{ Created, Skipped, Errors }.
- `ExportTestCases(ctx, projectID uuid.UUID, format string) (io.Reader, string, error)`: Load test cases, export to specified format. Return reader + filename.
- `ExportTestRunReport(ctx, runID uuid.UUID, format string) (io.Reader, string, error)`: Load run with results, export to PDF/CSV/JSON.
