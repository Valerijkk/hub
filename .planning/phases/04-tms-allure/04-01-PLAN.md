1. Create **ent_repository.go**: Implement Repository interface using Ent client. Follow tracker ent_repository.go pattern. Key implementation details:
   - CreateTestCase: Increment project test_case_counter atomically (same pattern as tracker task_counter), generate case_key as `{project.Key}-TC-{counter}`. Eager-load edges on return.
   - GetTestCase: Eager-load suite, created_by, labels, components, linked_issues edges.
   - ListTestCases: Support pagination (offset/limit), filtering by suite_id, status, priority, search (title LIKE). Return items + total count.
   - UpdateTestCase: Increment version field. Clear and re-set labels/components edges as needed.
   - CreateTestCaseVersion: Store JSONB snapshot of all test case fields.
   - ListSuites: Use recursive query or fetch all suites for project and build tree in-memory (practical for <1000 suites).
   - TestRun CRUD: Standard Ent operations. UpdateTestRunStats updates the pre-computed counters.
   - BatchCreateTestResults: Bulk insert for Allure import (used in plan 04-03).
   Constructor: `NewEntRepository(client *ent.Client)`.

2. Create **service.go** (TMSService):
   - Constructor: `NewTMSService(repo Repository) *TMSService`
   - CreateTestCase: Validate request, call repo.CreateTestCase, return DTO.
   - UpdateTestCase: Create version snapshot BEFORE updating (call repo.CreateTestCaseVersion with current state, then repo.UpdateTestCase). Increment version.
   - RollbackTestCase: Load version snapshot, apply as update, create new version entry marking rollback.
   - LinkTestCaseToIssue/UnlinkTestCaseFromIssue: Manage bidirectional edges.
   - CreateTestRun/UpdateRunStatus: Implement state machine (created->in_progress->completed/aborted, completed->in_progress for reopen). Reject invalid transitions with 400.
   - All other CRUD: Delegate to repo, map to DTOs.
   GoDoc IN RUSSIAN.

   - RegisterRoutes signature: `(api fiber.Router, authMw fiber.Handler, rbacSvc *rbac.RBACService)`
   - Route group: `/projects/:projectId/tms` with authMw
   - Test cases: POST/GET/GET/:caseKey/PUT/:caseKey/DELETE/:caseKey under `/cases`
   - Versions: GET /:caseKey/versions, POST /:caseKey/rollback/:versionId under `/cases`
   - Issue links: POST/DELETE /:caseKey/links under `/cases`
   - Suites: POST/GET/PUT/:suiteId/DELETE/:suiteId under `/suites`
   - Components: POST/GET/DELETE/:componentId under `/components`
   - Runs: POST/GET/GET/:runId/PUT/:runId/status/POST/:runId/reopen under `/runs`
   - Results: POST/PUT/:resultId/GET under `/runs/:runId/results`

   - Extract projectId from params with `utils.CopyString(c.Params("projectId"))`.

   - Extract userID from context via `c.Locals("userID")`.
