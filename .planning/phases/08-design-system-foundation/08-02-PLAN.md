<task type="auto">
  <name>Task 2: Add noise texture overlay and verify build</name>
  <files>frontend/src/app.css</files>
  <read_first>
    - frontend/src/app.css
  </read_first>
  <action>
Add the noise texture overlay to the `@layer base {}` section, right after the body rule. Insert the following CSS inside `@layer base`:

```css
  /* Noise texture overlay -- subtle grain from mockups */
  body::after {
    content: '';
    position: fixed;
    inset: 0;
    z-index: var(--z-noise, 9999);
    pointer-events: none;
    opacity: .3;
    background: url("data:image/svg+xml,%3Csvg viewBox='0 0 512 512' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='n'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='.9' numOctaves='4' stitchTiles='stitch'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23n)' opacity='.03'/%3E%3C/svg%3E");
  }
```

This must be INSIDE `@layer base { ... }`, placed after the existing body rule.

Key points:
- z-index uses `var(--z-noise, 9999)` -- the fallback 9999 is below Radix portal z-index (typically 10000+), so dropdowns/dialogs will render above the noise
- `pointer-events: none` ensures the overlay is non-interactive
- opacity .3 outer * .03 inner = extremely subtle grain, matching all 11 mockups
- `position: fixed; inset: 0` covers the entire viewport

After adding the overlay, run the Vite build to confirm everything compiles:

```bash
cd frontend && npx vite build --mode development
```

If the build fails, check for CSS syntax errors (missing semicolons, unclosed brackets) and fix.

Also verify no !important crept back in:
```bash
grep -c "!important" src/app.css
```
