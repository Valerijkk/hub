   - Поля: id (UUID), egress_id (string), status (enum: recording/processing/ready/failed), file_path (string -- S3 key), file_size (int64, default 0), duration_seconds (int, default 0), started_at (time), ended_at (optional time), created_at.
   - Edges: call (M2O к Call), project (M2O к Project), started_by (M2O к User).

2. Создать Ent-схему `ScheduledCall` (`backend/ent/schema/scheduledcall.go`):
   - Поля: id (UUID), title (string), description (optional string), scheduled_at (time -- следующее время), rrule (optional string -- RFC 5545 RRULE для повторяющихся), channel_id (UUID), created_by (UUID), is_active (bool, default true), created_at, updated_at.
   - Edges: project (M2O к Project), channel (M2O к Channel).
   - Index: (channel_id, scheduled_at), (is_active, scheduled_at).

3. Запустить `go generate ./ent`.

4. `go get github.com/teambition/rrule-go`.

5. Создать `recording.go` -- RecordingService (CALL-04, CALL-05):
   - Конструктор принимает lksdk.EgressClient (созданный через lksdk.NewEgressClient(url, apiKey, apiSecret)), S3Config, repo, nats.
   - StartRecording(ctx, callID, userID):
     - Проверить лимит: CountActiveRecordings() >= 2 -> ошибка.
     - Создать EgressRequest: RoomCompositeEgressRequest с FileOutput в S3 (путь: recordings/{projectID}/{callID}.mp4). S3Upload с endpoint, bucket, accessKey, secretKey от SeaweedFS config.
     - Вызвать egressClient.StartRoomCompositeEgress.
     - Сохранить Recording в БД (status=recording).
     - Опубликовать NATS event `calls.recording.started` -- чтобы уведомить участников (UI показывает индикатор записи).
   - StopRecording(ctx, recordingID):
     - Загрузить Recording, вызвать egressClient.StopEgress(egressID).
     - Обновить status=processing.
   - OnEgressEnded(ctx, egressID, fileInfo):
     - Обработчик вызывается из LiveKit webhook (egress_ended event).
     - Обновить Recording: status=ready, file_size, duration.
     - Опубликовать NATS event для публикации ссылки в канал мессенджера.
   - ListProjectRecordings(ctx, projectID): список записей проекта с пагинацией.
   - GetRecordingDownloadURL(ctx, recordingID): presigned S3 URL для скачивания.

6. Создать `scheduled.go` -- ScheduledCallService (CALL-02):
   - CreateScheduledCall(ctx, projectID, channelID, userID, req): создаёт запланированный звонок. Если rrule задан -- парсит через rrule.StrToRRule, вычисляет next occurrence.
   - ListScheduledCalls(ctx, channelID): список запланированных.
   - DeleteScheduledCall, UpdateScheduledCall.
   - ProcessDueScheduledCalls(ctx): вызывается cron-задачей (каждую минуту). Находит ScheduledCall с scheduled_at <= now и is_active=true. Для каждого:
     - Публикует NATS event `calls.scheduled.due` с channel_id (UI показывает уведомление "Запланированный звонок начинается").
     - Если rrule есть -- вычисляет следующее вхождение, обновляет scheduled_at. Если вхождений больше нет -- is_active=false.
     - Если rrule нет -- is_active=false.

7. Обновить `handler.go` -- добавить эндпоинты:
   - POST /api/calls/:callId/recording/start -- StartRecording.
   - POST /api/calls/:callId/recording/stop -- StopRecording.
   - GET /api/projects/:projectId/recordings -- ListProjectRecordings (CALL-05).
   - GET /api/recordings/:recordingId/download -- GetRecordingDownloadURL.
   - POST /api/projects/:projectId/scheduled-calls -- CreateScheduledCall.
   - GET /api/channels/:channelId/scheduled-calls -- ListScheduledCalls.
   - PUT /api/scheduled-calls/:id -- UpdateScheduledCall.
   - DELETE /api/scheduled-calls/:id -- DeleteScheduledCall.

8. Обновить `service.go` -- добавить обработку webhook event egress_ended в OnRoomFinished или добавить новый OnEgressEnded.

9. Добавить в main.go:
   - Создать EgressClient (lksdk.NewEgressClient).
   - Создать RecordingService, ScheduledCallService.
   - Запустить горутину для ProcessDueScheduledCalls (ticker каждые 60 секунд).
   - Зарегистрировать новые эндпоинты.

10. Unit-тесты: StartRecording (лимит), ScheduledCall с rrule (вычисление следующего), OnEgressEnded (обновление статуса).
