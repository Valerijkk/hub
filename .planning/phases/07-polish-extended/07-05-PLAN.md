   - `webhookendpoint.go`: id (UUID), url (string), secret (string -- для HMAC подписи), events ([]string -- JSON array подписанных событий), is_active (bool, default true), created_at. Edge: project (M2O к Project).
   - `webhookdelivery.go`: id (UUID), event_type (string), payload (JSON), status_code (int), response_body (optional string), error (optional string), delivered_at (time). Edge: endpoint (M2O к WebhookEndpoint).
   - `backuprecord.go`: id (UUID), s3_key (string), file_size (int64), status (enum: in_progress/completed/failed), error_message (optional string), created_at. No edges (system-level).
   - `environment.go`: id (UUID), name (string), label (enum: dev/staging/prod/custom), config (JSON -- {browser, os, version}), created_at. Edge: project (M2O к Project). Добавить optional edge environment к TestRun schema.
   - `projecttemplate.go`: id (UUID), name (string), description (optional string), template_type (enum: empty/software_dev/qa/kanban_simple/custom), config (JSON -- snapshot: statuses, labels, boards, custom_fields), is_system (bool, default false), created_at. Edge: created_by (M2O к User, optional для system templates).

Работает ПАРАЛЛЕЛЬНО с JWT auth (если JWT header есть -- JWT middleware, если X-API-Key -- API key middleware).

     - WebhookDispatcher: JetStream durable consumer "webhook-dispatcher" на stream EVENTS.
     - При получении события: найти все WebhookEndpoint с is_active=true и events содержащим msg.Subject(). Для каждого: подписать payload HMAC-SHA256 с endpoint.Secret, POST на endpoint.URL с заголовками X-Hub-Signature-256 и X-Hub-Event. Записать WebhookDelivery. Retry с exponential backoff (3 попытки, 1s/5s/30s).
     - CreateEndpoint, ListEndpoints, UpdateEndpoint, DeleteEndpoint.
