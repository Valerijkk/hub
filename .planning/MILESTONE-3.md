# Milestone 3: AI Chat Hub

**Defined:** 2026-03-22
**Depends on:** Milestone 2 (production deployment, messenger infrastructure)
**Status:** SHIPPED Phase 17–19 (2026-06-22)

## Vision

Встроенный AI-ассистент в мессенджере Hub, доступный без VPN из России. Команда общается с ИИ прямо в рабочем пространстве — генерация кода, ответы на вопросы, анализ задач, помощь с тестами. Поддержка нескольких бесплатных/дешёвых провайдеров с возможностью переключения.

## Phase 13: AI Chat Integration

**Goal:** Пользователи могут общаться с AI-ботом в мессенджере Hub через бесплатные API, доступные из России без VPN.

**Depends on:** Phase 9 (production deploy), Phase 3 (messenger infrastructure)
**Complexity:** L (Large)
**Priority:** P1

### Requirements

#### AI Provider Infrastructure

- [x] **M3-001**: Абстракция провайдера — единый интерфейс `AIProvider` с методами `Chat(messages) → response`, `StreamChat(messages) → stream`
- [x] **M3-002**: GigaChat (Сбер) провайдер — OAuth2 авторизация, API v1, поддержка функций, бесплатный tier для физлиц
- [x] **M3-003**: YandexGPT провайдер — IAM токен, Completion API, бесплатный tier (GPT Lite), поддержка стриминга
- [x] **M3-004**: DeepSeek провайдер — OpenAI-совместимый API, модели deepseek-chat/deepseek-coder, ~$0.14/1M токенов
- [x] **M3-005**: Mistral провайдер — API из EU, модели mistral-small (бесплатный tier), поддержка function calling
- [x] **M3-006**: Ollama провайдер (self-hosted) — для тех кто хочет запустить модель локально (llama3, codellama, mistral)
- [x] **M3-007**: Admin настройка — выбор активного провайдера, API ключи, лимиты использования на пользователя/день
- [x] **M3-008**: Fallback цепочка — если один провайдер недоступен, автоматически переключается на следующий

#### AI Bot в мессенджере

- [x] **M3-009**: Системный бот `@hub-ai` в мессенджере — можно писать в DM или упоминать в каналах
- [x] **M3-010**: Стриминг ответов — бот печатает ответ в реальном времени (typing indicator → постепенное появление текста)
- [x] **M3-011**: Контекст беседы — бот помнит последние 20 сообщений в треде/DM для контекстных ответов
- [x] **M3-012**: Markdown рендеринг — бот отвечает с форматированием (код, списки, таблицы, жирный/курсив)
- [x] **M3-013**: Code highlighting — блоки кода с подсветкой синтаксиса и кнопкой "Копировать"
- [x] **M3-014**: Системный промпт — настраиваемый админом, по умолчанию: "Ты AI-ассистент команды разработки, помогаешь с кодом, тестами, документацией"

#### Интеграция с Hub данными

- [x] **M3-015**: Команда `/ai summarize` — суммаризация треда или канала за период
- [x] **M3-016**: Команда `/ai test-cases [ISSUE-KEY]` — генерация тест-кейсов из описания задачи
- [x] **M3-017**: Команда `/ai review [PR-URL]` — анализ PR и генерация код-ревью комментариев
- [x] **M3-018**: Команда `/ai explain [CODE]` — объяснение кода на русском
- [x] **M3-019**: Команда `/ai translate [TEXT]` — перевод текста (RU↔EN)
- [x] **M3-020**: Команда `/ai sql [ВОПРОС]` — генерация SQL запроса из описания на русском
- [x] **M3-021**: RAG по документации проекта — бот может искать ответы в README, docs/, и комментариях к задачам

#### UI компоненты

- [x] **M3-022**: AI чат панель — можно открыть из любого места (кнопка в topbar или Ctrl+Shift+A)
- [x] **M3-023**: Inline AI в редакторе задач — кнопка "Спросить AI" при редактировании описания задачи
- [x] **M3-024**: AI suggestions в message composer — автодополнение сообщений (опционально, по Tab)
- [x] **M3-025**: Индикатор использования — сколько запросов осталось на сегодня (для бесплатных тиров)
- [x] **M3-026**: Переключатель модели — пользователь может выбрать модель из доступных (GigaChat, YandexGPT, DeepSeek)

#### Безопасность и лимиты

- [x] **M3-027**: Rate limiting — максимум запросов в минуту/час/день на пользователя (daily 500; per-provider RPM admin)
- [x] **M3-028**: Content filtering — фильтрация запросов на генерацию вредоносного кода, XSS, SQL injection
- [x] **M3-029**: Логирование — все AI запросы логируются в audit log (без содержимого, только метаданные: кто, когда, провайдер, токены)
- [x] **M3-030**: Приватность — данные не отправляются внешним API без согласия пользователя (настройка в профиле)

### Success Criteria

1. Пользователь может написать `@hub-ai` в любом канале и получить ответ от AI в течение 5 секунд
2. Стриминг работает — ответ появляется постепенно, а не целиком после задержки
3. Бот корректно рендерит Markdown с подсветкой кода
4. Команда `/ai test-cases HUB-123` генерирует релевантные тест-кейсы из описания задачи
5. Работает из России без VPN через GigaChat/YandexGPT/DeepSeek
6. Admin может переключать провайдера и устанавливать лимиты

### Plans: 5 plans

- 13-01: AI Provider абстракция + GigaChat + YandexGPT провайдеры (Go backend)
- 13-02: DeepSeek + Mistral + Ollama провайдеры + fallback цепочка + admin настройки
- 13-03: AI бот в мессенджере — @hub-ai, стриминг, контекст, markdown, code highlighting
- 13-04: Команды (/ai summarize, test-cases, review, explain, translate, sql) + RAG
- 13-05: UI — AI панель, inline AI в редакторе, suggestions, usage indicator, модель selector

|-----------|----------------|-----|-------------|-------------------|
| GigaChat (Сбер) | Да, для физлиц | Не нужен | Отлично | Свой API |
