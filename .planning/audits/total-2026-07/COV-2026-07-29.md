## Command

Host services: `deployments_*` postgres/mongo/redis/nats already up on localhost (`docker-compose.local.yml` hit port 27017 already allocated).

```powershell
$env:POSTGRES_TEST_URL = 'postgresql://hub:hub@localhost:5432/hub?sslmode=disable'
$env:MONGODB_TEST_URL  = 'mongodb://hub:hub@localhost:27017/?authSource=admin'
$env:CGO_ENABLED = '1'

# PowerShell: quote -coverpkg / -coverprofile (bare ./internal/... breaks arg parsing)
go test -tags=hubtest -count=1 -timeout=1200s -covermode=atomic `
  "-coverpkg=github.com/valerii/hub/backend/internal/..." `
  ./testframework/... `
  "-coverprofile=$PWD\cov.out"

go tool cover "-func=cov.out"
```

**Note:** On PowerShell, unquoted `-coverpkg=./internal/...` is misparsed (coverprofile missing / 0% lines). Use the full module path in quotes.
