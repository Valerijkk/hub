# Мессенджер -- Тестовая документация

## Соглашение об именовании

Идентификатор тест-кейса: `TC-MSG-{XX}-{NN}`, где:
- `MSG-{XX}` -- идентификатор требования (MSG-01, MSG-02 и т.д.)
- `NN` -- порядковый номер теста внутри требования

Формат описания каждого тест-кейса:
- **ID**: уникальный идентификатор
- **Описание**: что проверяется
- **Предусловия**: начальное состояние
- **Шаги**: последовательность действий
- **Ожидаемый результат**: критерий прохождения
- **Приоритет**: высокий / средний / низкий
- **Автоматизация**: команда `go test` или `manual`

## MSG-01: Личные сообщения и групповые чаты

### TC-MSG-01-01: Создание DM между двумя пользователями

- **ID**: TC-MSG-01-01
- **Описание**: Проверка создания личного чата (DM) между двумя пользователями
- **Предусловия**: Два пользователя (UserA, UserB) аутентифицированы
- **Шаги**:
  1. UserA отправляет POST `/api/messenger/dm` с телом `{"target_user_id": "UserB_ID"}`
  2. Проверить ответ
- **Ожидаемый результат**: Статус 200, в ответе `channel_type = "dm"`, канал содержит обоих пользователей, `dm_key` установлен
