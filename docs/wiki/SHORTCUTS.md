# Горячие клавиши

## Глобальные

| Клавиша | Действие |
|---------|----------|
| `Ctrl+K` | Глобальный поиск (задачи, тест-кейсы, каналы, пользователи) |
| `Ctrl+N` | Создать новую задачу |

## Мессенджер

| Клавиша | Действие |
|---------|----------|
| `Enter` | Отправить сообщение |
| `Shift+Enter` | Новая строка в сообщении |
| `Ctrl+V` | Вставить файл из буфера обмена |

## Редактор (Plate)

| Клавиша | Действие |
|---------|----------|
| `Ctrl+B` | Жирный текст |
| `Ctrl+I` | Курсив |
| `Ctrl+E` | Inline код |
| `` ``` `` | Блок кода |
| `@` | Упоминание пользователя |
