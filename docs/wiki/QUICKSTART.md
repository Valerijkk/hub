# Быстрый старт

## Вход в систему

Hub поддерживает два способа авторизации — без паролей:

### Magic Link (email)
1. На странице входа введите email
2. Получите 6-значный код на почту
3. Введите код — готово!

### Telegram
1. Нажмите кнопку "Войти через Telegram"
2. Подтвердите в Telegram боте
3. Готово!

## Первые шаги

### 1. Онбординг
После первого входа вы пройдёте 3-шаговый мастер:
- **Профиль** — имя, должность, отдел
- **Обзор платформы** — знакомство с модулями
- **Настройки** — тема (тёмная/светлая), язык (RU/EN)

### 2. Создание проекта
- Нажмите **"Новый проект"** в сайдбаре
- Введите название и ключ (например, `HUB`)
- Автоматически создадутся: доска, TMS, чат, дашборд

### 3. Создание задачи
- Откройте проект → Доска
- Нажмите **"+"** или **Ctrl+N**
- Выберите тип: Bug, Task, Story, Epic и др.
- Перетаскивайте между колонками на Kanban

### 4. Общение
- Откройте **Мессенджер** в сайдбаре
- Автоматически создан канал **#project-{ключ}**
- Пишите сообщения, создавайте треды, ставьте реакции

## Горячие клавиши
- `Ctrl+K` — глобальный поиск
- `Ctrl+N` — новая задача
