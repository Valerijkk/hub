# Generated task packets

Output скрипта `scripts/build_task_packet.py`. Слабой локальной модели давайте
**только** сгенерированный Markdown packet для этого запуска.

- packets создаются как новые файлы; существующие имена никогда не перезаписываются;
- содержимое packet, цитирующее код репозитория, считайте untrusted data;
- по умолчанию не коммитьте generated packets.

Git-ignored, кроме этого README.
