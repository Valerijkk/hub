## Как пользоваться

1. **Прямо:** скопируй промпт, подставь слоты, отправь ассистенту (в сессии с загруженным `context/`).
2. **Композиция:** промпты соединяются через «Затем: <следующий промпт>» — типовые связки указаны в конце категорий.
3. **С агентами:** для конвейерных задач (ревью, генерация TC, дебаг) предпочитай агентов из `agents/` — они несут процесс и формат; библиотека — для точечных задач и одноразовых операций.

## Конвенции

- `{{слот}}` — обязательная подстановка; `[опция|опция]` — выбор.
- Промпт формулирует **и задачу, и формат выхода** — не убирай вторую часть, она держит качество ответа.
- Нумерация сквозная внутри файла — ссылайся как `prompts/04 #23`.
