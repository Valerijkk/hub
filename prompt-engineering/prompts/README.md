## Как пользоваться

1. **Прямо:** скопируй промпт, подставь слоты, отправь ассистенту (в сессии с загруженным `context/`).
2. **Развёрнуто (рекомендуется):** каждый промпт — это слот `[ЧТО]` [мастер-шаблона](../agents/templates/_MASTER-PROMPT-TEMPLATE.md). Оберни его по **профилю своей категории** (блок «Разворачивание по мастер-шаблону» в шапке каждого файла: роль, контекст, формат, техники, температура, верификация) — получишь production-промпт вместо однострочника.
3. **Эталоны:** [`EXPANDED-EXAMPLES.md`](EXPANDED-EXAMPLES.md) — 12 полностью развёрнутых промптов (по одному на категорию, разворот `#1` каждого файла) + сводная таблица профилей. Смотри как выглядит результат, повторяй для любого из 1000.
4. **Композиция:** промпты соединяются через «Затем: <следующий промпт>» — типовые связки указаны в конце категорий.
5. **С агентами:** для конвейерных задач (ревью, генерация TC, дебаг) предпочитай агентов из `agents/` — они несут процесс и формат; библиотека — для точечных задач и одноразовых операций.

## Почему не все 1000 развёрнуты

Полная форма мастер-шаблона × 1000 = ~40k строк одинакового boilerplate (`[ФОРМАТ]`, `[ПАРАМЕТРЫ]`, `[УСЛОВИЯ]` повторяются внутри категории почти дословно). Это ровно тот шаблонный шум, который ловит [`anti-ai-check`](../skills/anti-ai-check/SKILL.md). Поэтому повторяющаяся часть вынесена **один раз на категорию** (профиль в шапке файла), уникальная часть — задача — осталась в 1000 однострочников, а результат разворота показан в 12 эталонах. Разворачивается любой промпт за 30 секунд, библиотека остаётся навигируемой.

## Конвенции

- `{{слот}}` — обязательная подстановка; `[опция|опция]` — выбор.
- Промпт формулирует **и задачу, и формат выхода** — не убирай вторую часть, она держит качество ответа.
- Нумерация сквозная внутри файла — ссылайся как `prompts/04 #23`.
