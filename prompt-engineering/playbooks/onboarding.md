# Playbook: онбординг тулкита в новый проект

> Цель: от копирования папки до рабочего конвейера агентов. Обычно 1 сессия.

## Шаги

```
1. КОПИРОВАНИЕ
   cp -r prompt-engineering/ <проект>/
   Ничего не редактировать руками — вся адаптация через context-intake.

2. INTAKE (главный шаг)
   Прогнать skills/context-intake/SKILL.md (full).
   Выход: 4 заполненных context/-дока + Intake Report.
   Гейт: в отчёте 0 незаполненных секций без TODO(intake)-пометки;
   все канонические команды либо проверены запуском, либо помечены.

3. РАЗРЕШЕНИЕ TODO(intake)
   Каждый TODO — либо факт найден человеком и вписан (с пометкой <!-- manual -->),
   либо осознанно оставлен («perf-тестов нет и не планируется»).
   Расхождения «факт кода ↔ style guide» — решает владелец, решение в канон.

4. ПОДКЛЮЧЕНИЕ АГЕНТОВ
   agents/*.md → в механизм агентов инструмента (INSTALL.md Шаг 3).

5. SMOKE-ТЕСТ КОНВЕЙЕРА (по одному запуску каждого)
   a. reviewer + templates/review-request.md — на последний PR с тестами.
   b. tc-generator + templates/test-case-generation.md — на одну фичу со спекой.
   c. test-verification — на выход шага b.
   d. anti-ai-check — на весь репозиторий (первый прогон даст исторический долг —
      зафиксировать как baseline, не чинить всё сразу).
   e. naming-check — на одну тестовую директорию.
   Гейт: ни один агент не ответил «контекст не заполнен»; форматы выходов соблюдены.

6. ФИКСАЦИЯ БАЗОВОЙ ЛИНИИ
   Исторический долг из шагов 5d/5e — списком в трекер (не блокирует новую работу).
   Новые правила действуют с этого момента: новый код — по канону.

7. ИНТЕГРАЦИЯ С РЕГЛАМЕНТОМ ПРОЕКТА
   Ссылка на тулкит из правил проекта (Cursor rules / CLAUDE.md / AGENTS.md) +
   правило «тестовый код — через конвейер тулкита».
```

## Критерии готовности

- [ ] Intake Report: все доки filled
- [ ] Smoke: 5/5 сценариев отработали по форматам
- [ ] Baseline долга зафиксирован
- [ ] Регламент проекта ссылается на тулкит

## Типовые грабли

| Симптом | Причина | Фикс |
|---------|---------|------|
| Агенты дают общие советы вместо проектных | context/ не загружен в сессию агента | Проверить механизм подключения контекста инструмента |
| naming-check заваливает всё легаси | §5 канона (легаси-зоны) не заполнен | Дозаполнить NAMING-CONVENTIONS §5 |
| Команды из PROJECT-CONTEXT не работают | intake не проверял запуском | Перепрогнать intake шаг 1.5 с запуском |
| Верификация резает все TC как untraceable | Генерили без документации (из кода) | Найти/написать спеку или явный exploratory-режим |
