# pro-qa-ai — AI-слой для тестового фреймворка

**Версия:** `0.4.0-beta.1` · **Первый вход:** [START-HERE.md](START-HERE.md)

Переносимая AI-прослойка для инженера автоматизации. Она изучает
**существующий** тестовый фреймворк, превращает его факты и принятые
паттерны в проверяемый контекст для моделей, направляет специализированных
агентов и не даёт им работать на догадках.

Это **не** каркас тестового фреймворка и не каталог «магических промптов».

Все инструкции — на русском. Идентификаторы, пути, CLI-флаги и машинные
enum (`UNKNOWN`, `NOT_RUN`) остаются как в схемах.

## Зачем

Без слоя модель получает разовый промпт и каждый раз заново угадывает
устройство проекта. Со слоем она получает:

- проверенную карту **этого** тестового фреймворка с провенансом;
- решения **этой** команды из реальных ревью — то, чего нет ни в одной
  общей практике;
- заполненные практики тестов и кода с парами «плохо / хорошо»;
- рецепты, ссылающиеся на нужный контекст, а не копирующие его;
- команды с проверяемым критерием готовности вместо свободных заданий.

Эффективность **не измерена**: paired eval не гонялся, статус `NOT_RUN`.
Заявления «ускоряет в N раз» без замера запрещены — протокол замера
лежит в [`docs/ROI-METRICS.md`](docs/ROI-METRICS.md).

## Как устроен пакет

Три вопроса — три места, куда смотреть:

```
Что запустить?          COMMANDS.md → skills/
Чему следовать?         standards/
Как выполнять работу?   workflows/
```

Факты о конкретном проекте собирает `tf-init` в `context/projects/<profile>/`.
Записи работы — задачи, дефекты, обсуждения — в `work/`.

## Быстрый старт

```
1. Поставь пакет в репозиторий тестового фреймворка — INSTALL.md
2. tf-init     изучит репозиторий и заполнит контекст
3. tf-status   скажет, что делать дальше
4. дальше командами: tf-cases, tf-cover, tf-gate, tf-review, tf-triage
```

Замечания коллег с ревью переносит **человек** в
`standards/team-review/threads/inbox/`, дальше `tf-curate` превращает их
в проверяемые правила `CHECK-*`.

## Два принципа, на которых всё держится

**Знание команды сильнее общих практик.** Треды из реальных ревью
([`standards/team-review/`](standards/team-review/threads/README.md))
читаются ревьюером **до** общих практик. Общие правила модель знает и
так; чего она не знает — что именно эта команда на этом продукте считает
ошибкой. Полная лестница приоритета —
[`standards/README.md`](standards/README.md).

**Работа на догадках запрещена.** Команда без свежего контекста не
запускается: сначала `tf-init` или `tf-refresh`. Факт, которого нет в
репозитории, помечается `UNKNOWN` и выносится в вопросы, а не заменяется
правдоподобной догадкой.

## Конвенции

- `{{placeholder}}` — слот для подстановки: из активного профиля или руками
- `PASS` / `FAIL` — результат проверки; `N/A: причина` — неприменимо
- `UNKNOWN` — факт не выяснен; `NOT_RUN` — проверка не выполнялась
- Severity: `CRITICAL > HIGH > MEDIUM > LOW`, критерии в
  [`standards/rules/30-severity-policy.md`](standards/rules/30-severity-policy.md)
- Входные документы самодостаточны; детали грузятся только когда на них
  ссылается задача
