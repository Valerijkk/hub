# Процессы — как выполнять работу

Три каталога о том, как делается типовая работа. Различаются масштабом.

| Каталог | Масштаб | Отвечает на вопрос |
|---------|---------|--------------------|
| [`playbooks/`](playbooks/README.md) | Целый поток работы | Как пройти путь от начала до конца |
| [`recipes/`](recipes/README.md) | Одна законченная работа | Что делать по шагам и чем подтвердить |
| [`prompts/`](prompts/README.md) | Кусок текста промпта | Из чего собрать задание |

## Когда что открывать

```
Не знаю, с чего начать              → playbook
Знаю что делать, нужен порядок      → recipe
Собираю задание агенту              → prompt fragments
```

Рецепт — самый практичный уровень: у него есть вход, шаги и **проверяемый
критерий готовности**. Рецепт без такого критерия — дефект рецепта.

## Границы

Плейбук не дублирует рецепт: он говорит, какие рецепты и в каком порядке
применять. Рецепт не дублирует правило: он ссылается на
[`../standards/rules/`](../standards/rules/README.md), а не пересказывает.

Копия правила в трёх местах расходится молча — правят одну, две
продолжают учить старому.
