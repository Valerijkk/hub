# Playbook: красный CI → зелёный с профилактикой

> Цикл вокруг test-debugger: triage до фикса, минимальный фикс правильного слоя, регрессия, профилактика класса.

Команда: `tf-triage`. Процедура — [`skills/tf-triage.md`](../../skills/tf-triage.md).

## Конвейер

```
красный тест/сьют (CI или локально)
│
1. ФИКСАЦИЯ ВХОДА
│    полный лог падения + ссылка на джобу + git-диапазон «что менялось»
│    (без полного лога дебаг не начинается — «упало что-то» не вход)
│
2. test-debugger (templates/debug-session.md)
│    triage: ROOT=code | test | infra | FLAKY | STOP
│    ├─ STOP → эскалация владельцу спеки; тест помечается известным-красным
│    │         с тикетом; НЕ подгоняется под текущее поведение
│    ├─ FLAKY → flaky-протокол (§4 агента); при массовости — templates/flaky-hunt.md
│    └─ code/test/infra → научный цикл §3 → root cause → минимальный фикс
│
3. РЕГРЕССИЯ (обязательные три круга, логи в отчёт)
│    a. упавший тест изолированно ×N
│    b. сьют домена целиком
│    c. смежные сьюты (общий код/фикстуры)
│
4. ПРОФИЛАКТИКА
│    нужен ли регрессионный тест на КЛАСС бага (не только инстанс)?
│    да → тест в том же diff, что и фикс
│    обновить: active profile TEST-ARCHITECTURE.md § Risks and known unknowns;
│    новый reusable антипаттерн проходит отдельные feedback/pattern curation gates
│
5. ГЕЙТ: test-code-reviewer на diff фикса
│    особый фокус: фикс теста при ROOT=test не «подгонка» (triage-обоснование
│    в отчёте цитирует спеку), регрессионный тест ловит класс
│
└─ 6. мерж; Debug Report прикладывается к тикету
```

## Правила

1. **Triage-вердикт пишется до фикса** и входит в отчёт. Фикс без вердикта — возврат.
2. **Один дебаг — один root cause.** Нашёл по пути второй баг → отдельный тикет, не расползание сессии.
3. **Красный мастер — приоритет над фичами.** Сьют, красный дольше дня, деградирует в «все привыкли» — это смерть сигнала CI.
4. **Быстрые маскировки запрещены:** retry, таймаут-увеличение, skip — только карантин с тикетом+дедлайном, фиксируется в active profile `TEST-ARCHITECTURE.md`.
5. **Flaky бюджет:** карантин > 2 недель без движения → эскалация владельцу домена.
