# Тест-кейсы: формат и примеры

Как оформляется тест-кейс, чтобы его мог выполнить человек, не писавший
его, и чтобы результат был однозначен.

## Обязательные поля

| Поле | Зачем | Признак плохого заполнения |
|------|-------|----------------------------|
| **ID** | Ссылка из отчёта, автотеста, дефекта | Отсутствует или не уникален |
| **Название** | Понять суть, не открывая кейс | «Проверка функционала», «Тест 5» |
| **Описание** | Что и зачем проверяем | Пересказ названия другими словами |
| **Требование** | Откуда взялся кейс | Пусто — кейс не трассируется |
| **Приоритет** | Что выполнять первым при нехватке времени | У всех P0 |
| **Уровень** | unit, integration, api, e2e | Пусто — непонятно, где выполнять |
| **Предусловия** | Состояние до начала | «Пользователь есть» без уточнения какой |
| **Данные** | Что подаём и почему именно это | Значения без обоснования |
| **Шаги** | Что делаем, по порядку | «Проверить, что работает» |
| **Ожидаемый результат** | ОДИН наблюдаемый исход | Два и более исхода в одном кейсе |
| **Постусловия** | Что убрать за собой | Пусто там, где создавались данные |

## Два правила, на которых ломаются чаще всего

**Один кейс — один ожидаемый результат.** Два результата означают два
кейса: иначе при провале непонятно, что именно не сработало, и в отчёте
получается «упал кейс», а не «сломалось конкретное поведение».

**Шаг описывает действие, а не намерение.** «Проверить корректность
отображения» — не шаг: два человека выполнят по-разному. «Открыть
страницу заказа, сравнить сумму в поле Итого с суммой из спецификации» —
шаг.

## Связь с автоматизацией

Кейс помечается одним из трёх статусов исполнимости:

```
автоматизируемый   есть автотест либо он будет написан
ручной             автоматизация нецелесообразна, причина указана
заблокирован       нужен доступ, стенд или данные, которых нет
```

**Заблокированные не считаются покрытием.** Кейс, который невозможно
выполнить, покрывает требование только на бумаге.

Когда автотест написан, в кейс проставляется его имя. Обратная связь
обязательна: из автотеста должна быть ссылка на ID кейса. Без второй
связи через месяц никто не поймёт, зачем тест написан.
