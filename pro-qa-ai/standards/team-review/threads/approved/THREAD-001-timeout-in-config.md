# THREAD-001 — Таймаут ожидания вынесен в конфиг окружения

## Контекст

Интеграционный тест на создание заказа. Тест ждёт, пока внешний платёжный
сервис подтвердит транзакцию. Локально проходил, в ночном прогоне падал
через раз.

## Код, вызвавший обсуждение

```python
def test_order_paid_after_confirmation(order_client, payment_stub):
    order = order_client.create(amount=100)
    payment_stub.confirm(order.payment_id)

    wait_until(lambda: order_client.get(order.id).status == "paid",
               timeout=5)
```

## Тред

**Ревьюер:**
> Пять секунд откуда? На стенде интеграции платёжный отвечает 12–15 секунд
> под нагрузкой, у нас из-за этого уже второй ночной прогон красный.

**Автор:**
> Локально хватает секунды с запасом. Поставить 30 везде?

**Ревьюер:**
> Нет, тогда падение по таймауту будет ждать полминуты на каждом тесте,
> и прогон растянется. Возьми из конфига окружения — там уже есть
> `EXTERNAL_WAIT_TIMEOUT`, локально 5, на интеграции 30.

## Чем закончилось

Договорились двое, тимлид подтвердил в чате команды. Правило распространили
на все ожидания внешних ответов.

## Как стало

```python
def test_order_paid_after_confirmation(order_client, payment_stub, env):
    order = order_client.create(amount=100)
    payment_stub.confirm(order.payment_id)

    wait_until(lambda: order_client.get(order.id).status == "paid",
               timeout=env.external_wait_timeout)
```

## Почему так, а не иначе

Общая практика говорит «не хардкодь магические числа» — этого мало, она не
объясняет, почему нельзя просто поставить большое число везде.

Причина конкретная: у нас два окружения с разницей в скорости внешнего
сервиса **в шесть раз**. Единое большое значение делает падения медленными
и растягивает прогон; единое малое делает ночной прогон нестабильным.
Значение обязано зависеть от окружения, и оно там уже есть.

## Границы

Не относится к ожиданию **внутренних** операций: там время предсказуемо,
и локальная константа уместна. Не относится к тестам, где таймаут сам
является проверяемым требованием — там значение из спеки, а не из конфига.

## Что проверять

Числовой литерал в аргументе таймаута или ожидания в интеграционных и E2E
тестах. Поиск по вызовам `wait_until`, `wait_for`, `until`, `timeout=`
с числом вместо ссылки на конфиг.
