# Входящие треды — сырое, до разбора

Сюда человек вставляет тред из мержреквеста **как есть**: код, реплики,
чем закончилось. Обезличивать на этом шаге не обязательно — это делает
`tf-curate` при переносе в `approved/`.

## Что здесь лежать не должно

Файлы отсюда **не участвуют в ревью** и **не входят в переносимый пакет**.
Но это не значит, что сюда можно класть что угодно:

- секреты, токены, строки подключения — не класть даже временно;
- персональные данные клиентов — не класть;
- всё остальное можно, включая имена коллег: их уберёт разбор.

Каталог под git не отслеживается по той же причине, по которой не
отслеживается сгенерированный контекст: содержимое принадлежит конкретной
команде и конкретному моменту.

## Как переносится дальше

```
вставил тред сюда
      ↓ tf-curate
обезличивание, выделение правила, проверка на дубль
      ↓
threads/approved/THREAD-NNN-<slug>.md + строка в индексе
```

Дубль не создаётся: если такое замечание уже разобрано, растёт
`seen_count` существующего треда. Дубли ломают сортировку по частоте, а
она и есть главная ценность счётчика.
